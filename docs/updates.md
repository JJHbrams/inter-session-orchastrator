# 앱 업데이트

앱 설정의 **업데이트 확인**에서 최신 버전을 확인합니다. Windows 설치 앱에서는 **다운로드 및 설치**를 누르면 설치 파일을 검증하고 앱을 닫은 뒤 설치·재시작합니다. 작업 중인 요청이나 보내지 않은 입력·첨부가 있으면 먼저 정리해야 합니다.

자동 확인은 기본으로 켜져 있습니다. 앱이 실행 중일 때 PC의 로컬 시간 기준 매일 오전 9시에 확인하며, 9시 이후 앱을 열면 그날 놓친 확인을 진행합니다. **나중에**를 선택하면 같은 날 같은 버전을 다시 알리지 않습니다. 자동 확인은 앱 설정에서 끌 수 있습니다.

브라우저에서는 릴리스 페이지에서 설치 파일을 받습니다. 1.2.0 이전 버전에는 업데이트 기능이 없으므로 최초 한 번은 설치 파일로 업데이트해야 합니다.

## 릴리스 파일

업데이트는 공개 GitHub 저장소 `JJHbrams/inter-session-orchastrator`의 최신 정식 릴리스를 사용합니다. 초안·사전 릴리스·현재 이하 버전은 설치하지 않습니다.

- 태그: `vMajor.Minor.Patch`
- Windows x64 설치 파일: `SessionRooms-Major.Minor.Patch-x64-setup.exe`
- 체크섬 파일: `SHA256SUMS.txt` (SHA-256 두 칸 공백 파일명 형식)

GitHub의 에셋 SHA-256 또는 체크섬 파일을 확인하고 다운로드된 파일을 다시 검증합니다. 설치 적용은 사용자가 선택해야 진행됩니다. 설치 실패 결과는 재시작한 앱에 표시합니다.
