# 에이전트 오피스

토론장 상단의 작업실에서 세션 캐릭터를 선택하면 기존 세션 상세를 볼 수 있습니다. 작업실은 접거나 크게 볼 수 있으며, 표시 선택은 이 PC에 저장됩니다.

Claude는 주황 별, Codex는 민트 매듭 캐릭터입니다. 확인된 파일 읽기·검색은 자료실, 파일 편집은 개발석, 명령 실행은 서버석에서 표시합니다. 응답이 끝나면 토론 테이블로 돌아오고, 완료가 확인된 서브에이전트는 출입문으로 이동합니다.

작업 상태는 토론장 전달 기록과 연결된 Claude/Codex의 로컬 세션 기록에서 읽습니다. 요청 대기와 응답 시작을 구분하며, 기록이 없거나 오래되면 상태 확인으로 표시합니다. 요청 내용만으로 작업을 추측하지 않습니다. 로컬 세션 기록은 읽기만 하고, 별도 도구 실행이나 세션 설정 변경은 하지 않습니다.

운영체제의 동작 줄이기 설정을 따르면 이동 애니메이션을 줄입니다. 창을 숨기거나 작업실을 접으면 애니메이션을 멈춥니다.
